# Engineering Documentation Generator

> A software engineering tool that automates the generation of standardized Markdown documentation while preserving human creativity and decision-making.

---

## About

Engineering projects often begin by creating multiple documentation files before implementation can start.

Although every project has different objectives, much of this documentation process is repetitive.

The Engineering Documentation Generator was created to automate repetitive documentation tasks while allowing engineers to focus on what truly requires human judgment: ideas, architecture, and technical decisions.

---

## Philosophy

> Automate repetitive work, not creative thinking.

The application assists developers by generating structured Markdown documents based on predefined templates while keeping the user in control of the final result through an interactive review process.

---

## Current Features

- README generation
- Technical Knowledge Document generation
- Interactive document review before saving
- Markdown template system
